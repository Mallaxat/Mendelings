Mendelings.Core
    +PetBuilder —  будет строить питомцев
    +Pet — модель питомца.
    +GeneticTrait — описание одного генетического признака.
    +GeneticsService — генетическая логика
    +PetService — игрова логика(сон, еда и тд)
    User - хранит информацию о пользователе
  
Mendelings.Data

    +MendelingsDbContext — Контекст для CodeFirst
    +PetRepository — вся работа с питомцами в БД: получить, сохранить, обновить, удалить, получить родителей, детей, поколения.
    +GeneticsRepository — вся работа с генетическими справочниками
    +PetConfiguration/GeneticTraitConfiguration  —  настройка для бд питомца и признаков

Mendelings.UI

    +AppearancePet-хранит структуру картинок для петов
    +AppearancePetService - собирает по пути картинки и переносит в  AppearancePet
    MainViewModel — навигация между экранами.
    +PetsSelectModel — список питомцев и выбор питомца.
    +PetViewModel — экран одного питомца + тамагочи
    +BreedingViewModel — выведение питомца
    GeneticsViewModel — варианты внешности
    +FamilyTreeViewModel — родословная
